# 风格标准（Style Standards）

> 循环式论文审稿优化Pipeline语言自然度与逻辑缜密度标准
> 对应评分维度6（文笔与文风，12分）与维度7（逻辑缜密度，10分）

---

## 一、语言自然度标准

### 1.1 断裂式表达的识别与替换

断裂式表达指使用机械编号切分论述，破坏段落叙事连贯性的表达方式。

#### 禁止使用的断裂式编号

| 禁止模式 | 问题 | 替换策略 |
|---------|------|---------|
| 第一...第二...第三... | 机械切分，无逻辑呼吸感 | 用自然过渡词连接，如"在...方面""具体到...层面""此外" |
| 首先...其次...再者...最后... | 列表式叙事，破坏论证节奏 | 用逻辑关系词连接，如"一方面...另一方面"仅限二元对比 |
| 1. 2. 3. | 公文式编号，非学术叙事 | 融入段落叙述，用语义连接替代数字编号 |
| 一方面...另一方面...（超过2项时） | 二元对比框架无法承载多元论述 | 改用递进或转折等逻辑关系 |
| 其一...其二...其三... | 文言式编号，生硬 | 改用现代学术叙事连接 |

#### 替换示例

**禁止**：
> 研究发现可以从三个方面理解。第一，平台算法重塑了内容可见性。第二，用户实践呈现出适应性特征。第三，文化权力关系发生了再生产。

**推荐**：
> 研究发现揭示了平台化语境下的三重机制。平台算法重塑了内容可见性的技术基础，用户的实践则展现出对此基础的适应性策略，而文化权力关系在这一过程中发生了再生产。

### 1.2 机械过渡句的识别与替换

机械过渡句指公式化的段落或章节衔接语，缺乏实质逻辑功能。

#### 禁止使用的机械过渡句

| 禁止模式 | 问题 | 替换策略 |
|---------|------|---------|
| 下文将从...维度展开 | 公式化预告，无信息量 | 直接进入论述，用语义连接替代 |
| 下文将围绕...展开讨论 | 同上 | 同上 |
| 下文将主要建议整合如下 | 公文式总结语 | 用实质性总结替代 |
| 值得注意的是 | 空洞强调，无实质功能 | 直接陈述值得注意的内容 |
| 需要指出的是 | 同上 | 同上 |
| 综上所述 | 套话式总结 | 用实质性归纳替代 |

#### 替换示例

**禁止**：
> 下文将从理论框架、研究设计、研究发现三个维度展开讨论。值得注意的是，理论框架的选择至关重要。

**推荐**：
> 理论框架的选取直接决定了分析视角的深度。本文整合编码/解码模型与平台可供性理论，以此审视跨文化意义的可见性组织。

### 1.3 公式化辞藻的识别与替换

公式化辞藻指空洞的修饰语与浮夸的学术修辞，不提供具体信息。

#### 禁止使用的公式化辞藻

| 禁止辞藻 | 问题 | 替换策略 |
|---------|------|---------|
| 深刻的/深刻地 | 空洞修饰，无具体指向 | 说明"深刻"的具体表现 |
| 极具/极具价值 | 浮夸修辞 | 说明价值的具体内容 |
| 不可或缺 | 绝对化表述 | 说明具体作用 |
| 至关重要 | 空洞强调 | 说明重要的具体原因 |
| 具有重要意义 | 套话 | 说明意义的具体内容 |
| 具有启示价值 | 套话 | 说明启示的具体内容 |
| 做出了值得肯定的努力 | 公文式评价 | 说明努力的具体成果 |
| 富有张力 | 空洞修辞 | 说明张力的具体表现 |
| 具有理论新意 | 套话 | 说明新意的具体内容 |

#### 替换示例

**禁止**：
> 本文具有重要的理论意义和实践价值，做出了值得肯定的努力，研究结论极具启示价值。

**推荐**：
> 本文将技术焦虑从单一障碍重新概念化为兼具抑制与驱动双重功能的动态变量，对既有技术焦虑研究构成了有价值的对话，为平台设计中的用户心理支持提供了可操作的干预方向。

### 1.4 翻译腔的识别与修复（6种类型）

翻译腔指受英语学术写作影响而产生的欧化句式，读起来不自然。

#### 类型1：被动句滥用

| 翻译腔 | 修复 |
|--------|------|
| 这一现象被广泛地观察到 | 研究者广泛观察到这一现象 |
| 该理论被应用于...分析 | 该理论用于...分析 |
| 数据被收集自... | 数据来自... |
| 结果被报告如下 | 结果如下 |

#### 类型2：长定语从句

| 翻译腔 | 修复 |
|--------|------|
| 基于对平台算法如何影响内容可见性的分析 | 分析平台算法对内容可见性的影响 |
| 那些在数字环境中成长起来的用户 | 数字环境中成长起来的用户 |
| 关于用户如何理解平台权力关系的研究 | 用户对平台权力关系的理解研究 |

#### 类型3：抽象名词堆砌

| 翻译腔 | 修复 |
|--------|------|
| 进行了...的研究 | 研究了... |
| 做出了...的分析 | 分析了... |
| 实现了...的探讨 | 探讨了... |
| 完成了...的考察 | 考察了... |

#### 类型4：逻辑连接词过度

| 翻译腔 | 修复 |
|--------|------|
| 因此，所以，由此可见（连用） | 保留一个，删除其余 |
| 然而，但是，尽管如此（连用） | 保留一个 |
| 此外，另外，除此之外（连用） | 保留一个 |

#### 类型5：冠词式表达

| 翻译腔 | 修复 |
|--------|------|
| 作为一个重要的因素 | 作为重要因素 |
| 在...的框架下 | 在...框架内 |
| 在...的基础上 | 基于... |

#### 类型6：主语冗余

| 翻译腔 | 修复 |
|--------|------|
| 本研究认为，本研究发现，本研究指出（连用） | 保留首个，后续省略主语 |
| 作者认为，作者发现 | 直接陈述观点 |

## 二、逻辑缜密度标准

### 2.1 句子过渡平滑性检测

句子过渡平滑性指句与句之间存在逻辑衔接，而非简单并列或跳跃。

#### 检测清单
- [ ] 相邻句子是否有逻辑关系（因果、递进、转折、对比、例证）
- [ ] 是否存在无衔接的句子跳跃（A句到C句，跳过B句）
- [ ] 是否存在主语频繁切换导致逻辑断裂
- [ ] 过渡词是否使用恰当（避免"然而""因此"过度使用，每页≤2次）

#### 平滑过渡示例

**生硬过渡**：
> 平台算法决定了内容可见性。用户通过适应性策略回应算法。文化权力关系在这一过程中再生产。

**平滑过渡**：
> 平台算法决定了内容可见性的技术基础。面对这一结构性约束，用户发展出一系列适应性策略。而正是算法约束与用户策略的持续互动，使文化权力关系在这一过程中发生了再生产。

### 2.2 段落逻辑呼吸感检测

段落逻辑呼吸感指段落内部论证有起承转合，而非平铺直叙。

#### 检测清单
- [ ] 段落是否有主题句（通常为首句）
- [ ] 主题句后是否有展开论证（而非直接跳到结论）
- [ ] 展开论证是否有经验材料支撑
- [ ] 段落结尾是否有小结或过渡（呼应主题句或引出下段）
- [ ] 段落内部是否有"理论预期→经验展示→理论对话"的节奏

#### 呼吸感良好的段落结构

```
[主题句] 平台算法通过推荐机制重塑了内容可见性的分配逻辑。
[展开1-技术机制] 推荐算法以用户历史行为为输入，以预测点击率为目标，对内容进行排序与分发。
[展开2-经验证据] 访谈数据显示，受访者普遍感知到"流量集中于少数内容"的现象（C-12，C-15）。
[展开3-理论对话] 这一发现与Gillespie（2014）的"算法权力"论形成对话，但本文进一步揭示了...
[小结/过渡] 算法的可见性分配并非中性技术过程，而是权力关系的制度化。
```

### 2.3 生硬切换的识别与修复

生硬切换指段落或章节之间缺乏过渡，直接跳转导致逻辑断裂。

#### 常见生硬切换类型

| 类型 | 表现 | 修复策略 |
|------|------|---------|
| 主题跳转 | 上段讲A，下段突然讲B，无关联 | 增设过渡句，说明A与B的逻辑关系 |
| 层次跳转 | 上段讲宏观，下段突然讲微观 | 增设层次转换说明 |
| 方法-发现跳转 | 方法部分直接跳到发现，无衔接 | 增设"基于上述方法，本研究发现..."的衔接 |
| 发现-讨论跳转 | 发现部分直接跳到讨论，无过渡 | 增设"上述发现的理论含义值得进一步讨论"的过渡 |

#### 修复示例

**生硬切换**：
> [上段] 编码过程采用三级编码，最终形成47个编码。
> [下段] 研究发现平台算法重塑了可见性分配。

**平滑过渡**：
> [上段] 编码过程采用三级编码，最终形成47个编码。
> [过渡] 基于上述编码结果，本研究从三个维度揭示了平台化语境下的可见性组织机制。
> [下段] 研究发现平台算法重塑了可见性分配。

### 2.4 过渡词/句的使用规范

#### 推荐使用的过渡方式

| 逻辑关系 | 推荐过渡 | 使用频率建议 |
|---------|---------|-------------|
| 递进 | "此外""不仅如此""进一步而言" | 每段≤1次 |
| 转折 | "然而""不过""需要辨析的是" | 每页≤2次 |
| 因果 | "因此""这意味着""由此可见" | 每段≤1次 |
| 例证 | "以...为例""具体而言" | 按需使用 |
| 对比 | "相比之下""与之不同" | 按需使用 |
| 总结 | "总体而言""综合来看" | 每节≤1次 |

#### 禁止过度使用的过渡词
- "然而"每页超过2次：扣分
- "因此"每段超过1次：扣分
- "值得注意的是"全文超过3次：扣分

## 三、标点规范

### 3.1 破折号使用规范

**使用场景**（仅限以下3种）：
1. 解释说明：破折号后内容是对前文的解释
2. 话题转换：破折号后内容转向相关但不同的话题
3. 声音停顿：模拟说话时的停顿

**数量限制**：全文≤15处

**禁止场景**：
- 用破折号代替冒号引出列表
- 用破折号代替逗号分隔并列成分
- 连续使用破折号（——......——）

### 3.2 冒号使用规范

**使用场景**（仅限以下3种）：
1. 引出直接引语：如"受访者表示："
2. 引出定义或公式：如"可见性定义为："
3. 标题与副标题分隔：如"可见性组织：平台化语境下的文化权力"

**禁止场景**：
- 用冒号引出长段论述（应直接陈述）
- 用冒号分隔句子成分
- 一段中连续使用多个冒号

### 3.3 引号使用规范

**使用场景**（仅限以下3种）：
1. 直接引语：引用受访者原话或文献原话
2. 特定概念：首次使用的新概念或带特殊含义的词语
3. 反讽或质疑：对某表述的质疑性使用

**禁止场景**：
- 用引号标注普通术语
- 过度使用引号标注"所谓"概念
- 中文引号字体必须为宋体（w:eastAsia设置）

### 3.4 分号使用规范

**使用场景**：并列分句之间的分隔

**数量限制**：全文≤10处

**禁止场景**：
- 用分号分隔非并列关系句子
- 一段中连续使用多个分号（超过2个）

### 3.5 省略号使用规范

**使用场景**：
1. 引语省略：引用时省略部分内容
2. 语意未尽：表述未尽之意

**禁止场景**：
- 用省略号代替具体数据或例证
- 用省略号表示"等等"（应直接用"等"）

## 四、句长和段落长度控制

### 4.1 句长控制标准

| 句子类型 | 字数上限 | 超标处理 |
|---------|---------|---------|
| 叙述句 | ≤30字 | 拆分为两个短句 |
| 分析句 | ≤40字 | 拆分或重组 |
| 复杂论证句 | ≤60字 | 必须拆分，提取主干 |

#### 句长超标示例

**超标（68字）**：
> 本研究通过对来自三个不同平台的用户生成内容进行多模态特征提取与机器学习分析，揭示了平台算法推荐机制与文化内容可见性之间的复杂互动关系。

**修复（拆分为3句）**：
> 本研究提取了三个平台用户生成内容的多模态特征。基于机器学习分析，研究揭示了算法推荐与内容可见性的互动。这一互动关系呈现出平台间的显著差异。

### 4.2 段落长度控制标准

| 段落类型 | 字数范围 | 超标/不足处理 |
|---------|---------|-------------|
| 标准段落 | 100-400字 | 超标拆分，不足合并 |
| 引言段落 | 500-700字 | 按引言结构规范 |
| 文献综述段落 | 1500-2500字（全节） | 分多个自然段 |
| 方法段落 | 600-1000字（全节） | 分多个自然段 |
| 发现段落 | 3000-4500字（全节） | 分多个自然段 |
| 结语段落 | 1200-2000字（全节） | 分多个自然段 |

#### 段落过长示例

**超标（520字，单段）**：
> [整段520字连续论述，无分段...]

**修复（拆分为2段）**：
> [第1段：技术机制分析，约250字]
> [第2段：用户实践分析，约270字，以过渡句衔接]

### 4.3 段落内部结构规范

**标准段落结构**（100-400字）：
1. **主题句**（首句）：概括段落核心论点
2. **展开论证**（2-4句）：论证主题句，含经验材料
3. **小结/过渡**（末句）：呼应主题句或引出下段

**禁止的段落结构**：
- 无主题句的"流水账"段落
- 主题句与展开论证脱节的段落
- 无小结或过渡的"戛然而止"段落

## 五、风格违规检测与修复流程

### 5.1 自动检测项（StyleGuard程序化检查）

| 检测项 | 阈值 | 违规处理 |
|--------|------|---------|
| 破折号数量 | ≤15处 | 超标则标记违规，要求削减 |
| 冒号使用场景 | 仅3种 | 超范围使用标记违规 |
| 引号使用场景 | 仅3种 | 超范围使用标记违规 |
| 分号数量 | ≤10处 | 超标则标记违规 |
| 断裂式编号 | 0处 | 出现即标记违规 |
| 机械过渡句 | 0处 | 出现即标记违规 |
| 公式化辞藻 | 0处 | 出现即标记违规 |
| 句长超标 | 复杂论证≤60字 | 超标标记违规 |
| 段落长度 | 100-400字 | 超标/不足标记违规 |
| "然而"频率 | 每页≤2次 | 超标标记违规 |

### 5.2 修复优先级

| 优先级 | 违规类型 | 修复要求 |
|--------|---------|---------|
| P0（绝对红线） | 断裂式编号、机械过渡句 | 必须立即修复，0容忍 |
| P1（高优先级） | 公式化辞藻、翻译腔 | 必须在当轮修复 |
| P2（中优先级） | 标点滥用、句长超标 | 应在当轮修复 |
| P3（低优先级） | 段落长度微调 | 可在下一轮修复 |

### 5.3 风格守卫闭环机制

```
Agent输出 → StyleGuard检测 → 违规记录 → ConstraintInjector注入 → Agent修复 → StyleGuard再检测
```

每轮循环中，StyleGuard检测的违规记录被注入下一轮的Agent指令中，形成"违规→注入→修复→再验证"的闭环，确保风格规则在多轮循环中不漂移。

## 正面引导：好语言的标准

> 此前本文件以"禁止模式"为主——识别并禁止断裂式表达、机械过渡句、公式化辞藻等违规模式。现补充"正面引导"，明确好语言的标准，使Agent在修复违规的同时有可追求的目标。

### 好语言的范本来源

好语言的标准参照 `style_exemplars.md` 中的范本段落。这些范本从真实CSSCI论文中提取，经过多轮审稿验证，代表了中文新闻传播学论文的语言质量上限。Agent在执行风格修复时，应以范本为参照，而非仅以"不违规"为目标。

### 好语言的5项核心特征

#### 1. 声音感

读起来像一个思维清晰的人在讲述，而非机器在输出。好论文有"说话的人"，读者能感受到作者的声音——判断、取舍、立场都隐含在措辞中。

**正面例句**：
> 算法接管一切带来的并非效率的线性提升，而是漏洞频出的"人工智障"。

#### 2. 呼吸感

长短句交替，段落有推进节奏，不僵硬化也不散文化。好段落的句子长度有起伏：短句收束、长句展开，形成呼吸般的节奏。

**正面例句**：
> N3的母亲更年期长期异常出血，多地检查后发现是严重盆腔炎。顺势把话题翻篇。

#### 3. 论证流动感

句与句之间有逻辑流动，不是论点+论据的机械拼接。好论文的论证像水流，而非积木——每句话都是上一句的自然延伸，而非独立模块的拼接。

**正面例句**：
> 在个体和社会的"遗忘"与妇女身体的"透明"中，代际之间的知识反哺使得母亲体内的节育环重新被看见。

#### 4. 学术口语感

学术语言与人类日常语言的自然融合，避免纯书面语的僵硬。好论文用学术概念说人话，而非用学术概念说机器话。

**正面例句**：
> 巧妇难为无米之炊，驱动人工智能和算法系统运行的恰恰是人类的劳动行为数据。

#### 5. 概念锚定感

核心概念在全文中反复出现并逐步深化，而非一次性使用后消失。好论文的核心概念像锚点，在全文中反复出现，每次出现都带着新的层次。

**正面例句**：
> "脚手架"概念在论文中反复出现并逐步深化——从"女儿作为脚手架"到"知识传播的脚手架"到"反哺的脚手架机制"。

## 语义衔接质量判断标准

> 本节与 `style_constraints.py` 中的 `TRANSITION_QUALITY_RULES` 对齐，定义高质量语义衔接的模式与判断标准。

### 高质量语义衔接的3种模式

#### 模式1：尾句铺垫型

前段末尾提出概念或问题，下段开头拾起并转向。两段之间通过"尾—首"呼应实现衔接，无需额外过渡词。

**示例**：
> [前段末] ……这一现象揭示了算法推荐的"信息茧房"效应。
> [下段首] 茧房效应并非算法的必然产物。

#### 模式2：概念桥接型

两段共享核心概念，但视角或层面不同。概念成为段落之间的"桥梁"，读者通过概念的延续感知逻辑流动。

**示例**：
> [前段] 从技术层面看，可见性是算法排序的结果……
> [下段] 从文化层面看，可见性是权力博弈的产物……

#### 模式3：问题牵引型

前段以设问收束，下段直接回应。设问制造悬念，回应提供答案，形成"问—答"的论证动力。

**示例**：
> [前段末] 那么，用户是否真的被动接受了算法的安排？
> [下段首] 答案是否定的。

### 语义衔接质量的3项判断标准

#### 标准1：信息增益

过渡句是否提供了新信息（而非仅用"此外""另外"占位）。高质量过渡应在衔接的同时推进论证，而非仅标记"我要换话题了"。

| 类型 | 示例 |
|------|------|
| ✅ 正面 | 算法不仅重塑了内容的可见性，也改变了用户感知自身价值的方式。 |
| ❌ 反面 | 此外，算法也影响了用户。 |

#### 标准2：逻辑桥梁

过渡是否建立了两段之间的逻辑关系（因果/递进/转折/并列）。高质量过渡应明确揭示逻辑关系，而非让读者自行推断。

| 类型 | 示例 |
|------|------|
| ✅ 正面 | 正是算法对可见性的重塑，使用户不得不发展出适应性策略。 |
| ❌ 反面 | 另外，用户也有适应性策略。 |

#### 标准3：概念延续

过渡是否延续了前文的核心概念（而非跳跃到新话题）。高质量过渡应让核心概念在段落间流动，而非断裂后重启。

| 类型 | 示例 |
|------|------|
| ✅ 正面 | 可见性的分配不仅影响内容，也重塑了创作者的劳动过程。 |
| ❌ 反面 | 除此之外，创作者的劳动也值得关注。 |

### 禁止的低质量过渡

以下4种过渡模式因缺乏语义衔接功能，一律禁止：

| 禁止模式 | 问题 |
|---------|------|
| "此外" + 无语义衔接 | 仅标记并列，未说明并列的逻辑关系 |
| "另外" + 无语义衔接 | 同上 |
| "同时" + 无语义衔接 | 仅标记共时，未说明共时的逻辑关系 |
| "除此之外" + 无语义衔接 | 仅标记补充，未说明补充的逻辑关系 |

**判断规则**：若过渡词后接的内容与前文无逻辑关系（因果/递进/转折/并列），则判定为"无语义衔接"，该过渡词应删除或替换为有实质逻辑功能的表述。

## 论证方式约束

### 论点-论据-分析比例

不同研究类型的论点、论据、分析应保持合理比例：

| 研究类型 | 论点 | 论据 | 分析 |
|---------|------|------|------|
| 质性研究 | 20% | 40%（引语/田野材料） | 40% |
| 量化研究 | 25% | 35%（数据/图表） | 40% |
| 理论研究 | 30% | 40%（理论推演） | 30% |

**核心原则**：分析占比不得低于论据占比。论据堆砌而无分析是常见问题，应确保每条论据后都有分析性回应。

### 概念生成时机

**规则**：在2-3条经验材料呈现之后，必须进行一次概念化提升。

**模式**：
```
经验材料1 → 经验材料2 → [概念命名] → 理论对话
```

**反模式**：
```
[概念命名] → 经验材料1 → 经验材料2（演绎式，非归纳式）
```

## 数字使用规范（v5.1 新增）

学术论文中的数字使用须遵循以下规范：

**数据数字用阿拉伯数字**：所有统计数据、样本量、回归系数、百分比、p 值、F 值、年份、页码等数据性数字一律使用阿拉伯数字。
- 合规示例：研究样本量为 4287 份；回归系数 β=0.234；p<0.001；2024 年；第 15 页
- 违规示例：研究样本量为四千二百八十七份

**严肃数字用汉字数字**：涉及历史事件、政治话语、文化语境的严肃数字须使用汉字数字。
- 合规示例：改革开放四十余年；新中国成立七十年以来；五四运动百年纪念
- 违规示例：改革开放 40 余年；新中国成立 70 年来

**判定标准**：语境决定数字形式。出现"新中国成立""改革开放""五四运动""辛亥革命""建党""抗战""解放战争"等历史事件语境时，其后数字须用汉字数字；出现"样本量""回归系数""百分比""p 值""年份"等数据语境时，其后数字须用阿拉伯数字。

**检测机制**：`detect_numeric_format_violations` 函数会自动检测违规数字使用并纳入 `run_full_style_audit` 违规汇总。

先提出概念再用材料验证属于演绎式写作，不符合CSSCI论文的归纳式论证规范。概念应从经验材料中"生长"出来，而非从理论中"推导"出来再找材料验证。

### 理论对话深度

**频率要求**：每节至少1次理论对话，理想2次，最多3次。

**理论对话的3种模式**：

| 模式 | 定义 | 示例 |
|------|------|------|
| 嵌入式 | 理论概念嵌入论证链条中 | "依循深度媒介化的思路，媒介可以被理解成……" |
| 对话式 | 将发现与既有理论进行对比 | "不同于弗洛里迪等人的设想，本研究发现……" |
| 升华式 | 从经验发现上升到理论命题 | "这意味着……" |

**注意**：理论对话不是文献综述的复述，而是将本研究的发现与既有理论进行实质性碰撞。避免"某某也指出……"式的平行罗列。

### 论证语态多样性

**规则**：每段应包含至少2种不同论证语态。

**6种论证语态**：

| 语态 | 模式 | 示例 |
|------|------|------|
| 让步-转折 | 虽然A，但B | "尽管平台提供了参与渠道，但这些渠道的结构性约束限制了实质参与。" |
| 递进-收束 | 不仅A，更B | "算法不仅重塑了可见性，更重构了创作者的劳动认同。" |
| 设问-自答 | A？B。 | "用户是否被动接受了算法安排？答案是否定的。" |
| 条件-推论 | 如果A，则B | "若将算法视为中性工具，则无法解释其权力效应。" |
| 修正-翻转 | 以为A，实为B | "表面上看是用户选择，实则是算法引导下的有限选择。" |
| 并列-辩证 | A与B互构 | "可见性分配与文化权力互为条件、相互构成。" |

**禁止**：3句以上连续使用同一语态。连续使用同一语态会导致论证节奏僵化，应在不同语态之间切换以保持论证活力。

## 摘要正面标准（★v1.4新增）

> 本章节基于真实CSSCI论文摘要特征提取，旨在解决摘要写作中"口水话过多"和"学术机械语言过多"的两极问题。
> 本章节为摘要审稿提供正面标准与识别清单，与 `style_exemplars.md` 的"## 摘要范本库（★v7.1新增）"章节配套使用。
> 核心策略：**以正面标准引导、以识别清单诊断、以修复策略校正**。

### 摘要结构5大特征

高质量摘要应具备以下5大结构特征，审稿时应以此为正面标准：

| # | 特征 | 正面表现 | 反面问题 |
|---|------|----------|----------|
| 1 | 以"问题情境"开篇 | 首句直接嵌入张力性问题或判断，背景为问题服务 | "口水话"：空泛背景铺垫 |
| 2 | 以"既有研究……而……"自然引出研究缺口 | 用对比句式自然引出研究定位 | "机械学术腔"：生硬说"本研究填补了……空白" |
| 3 | 方法以动词嵌入方式呈现 | 方法以"通过……""结合……"等动词结构嵌入问题陈述之后 | "机械学术腔"：方法独立成段罗列 |
| 4 | 发现以"研究发现："或"并认为"自然引出 | 发现部分呈现可观察的变量关系，具体而非抽象 | "口水话"：笼统说"发现了重要规律" |
| 5 | 贡献以"基于此""有助于"等承接式表达收束 | 贡献锚定在具体理论维度上 | "口水话"：空喊"具有重要意义" |

### "口水话"识别清单

"口水话"指摘要中空泛、无信息量、套话堆砌的表达。审稿时应识别以下5类口水话特征：

| # | 识别特征 | 典型表现 | 识别要点 |
|---|---------|---------|---------|
| 1 | 空泛背景铺垫 | "随着……的发展""在……背景下""伴随着……的推进" | 首句是否提供具体信息，而非泛泛而谈 |
| 2 | 无信息量开头 | "近年来，……日益重要""当前，……日益突出" | 开头是否建立认知张力，而非平铺直叙 |
| 3 | 笼统研究意义表述 | "本研究具有重要意义""具有重要的理论意义和实践价值" | 贡献是否锚定具体理论维度 |
| 4 | 重复背景陈述 | 同一背景信息用不同词语重复表达 | 是否存在信息冗余 |
| 5 | 空洞修饰语堆砌 | "深刻地""极具""高度""丰富而多元" | 修饰语是否提供具体指向 |

### "机械学术腔"识别清单

"机械学术腔"指摘要中术语堆砌、断裂式连接、方法独立罗列等机械化表达。审稿时应识别以下5类机械学术腔特征：

| # | 识别特征 | 典型表现 | 识别要点 |
|---|---------|---------|---------|
| 1 | 术语堆砌无解释 | 连续使用多个学术术语而无"——"或解释展开 | 术语是否承担解释功能，而非堆砌 |
| 2 | 断裂式编号连接 | "首先""其次""最后""第一""第二""第三" | 是否使用承接式表达而非断裂式编号 |
| 3 | 方法独立罗列不嵌入 | "本研究采用XX方法。样本量为XX。数据分析采用XX软件。" | 方法是否嵌入问题陈述之后 |
| 4 | 机械过渡句 | "研究发现如下""研究结果表明""具体而言" | 是否使用自然过渡词 |
| 5 | 公式化辞藻堆砌 | "做出了值得肯定的努力""富有张力""具有启示价值" | 辞藻是否提供具体信息 |

### 修复策略

#### （一）针对"口水话"的修复策略

| 修复前（口水话） | 修复后（问题情境） | 修复要点 |
|-----------------|-------------------|---------|
| "随着人工智能的发展，算法推荐日益重要。" | "在力图实现信息个性化传播的推荐算法环境中，肩负公共性与凝聚力使命的新闻如何继续发挥关系纽带的作用？" | 将背景熔铸为问题，建立认知张力 |
| "本研究具有重要的理论意义和实践价值。" | "对女性备孕过程中自我追踪实践的考察，有助于从人的主体性维度，理解当代数字生命政治中媒介技术的作用" | 贡献锚定具体理论维度 |
| "发现了重要规律" | "研究发现：在算法环境下，新闻联结用户的能力总体较弱且持续弱化——即便面向新闻消费者社群，新闻信息共现网络的内部连接紧密程度已不如非新闻信息" | 呈现可观察的具体变量关系 |

**修复步骤**：
1. 识别首句是否为"随着……的发展"式套话
2. 提取首句中的核心概念与张力
3. 将背景熔铸为问题情境或判断句
4. 用"既有研究……而……"对比句式自然引出研究缺口
5. 将笼统贡献改为锚定具体理论维度的承接式表达

#### （二）针对"机械学术腔"的修复策略

| 修复前（机械学术腔） | 修复后（动词嵌入） | 修复要点 |
|---------------------|-------------------|---------|
| "本研究采用参与式观察和访谈的方法。样本量为42人。数据分析采用NVivo软件。" | "通过参与式观察和访谈，本研究以医疗职业陪诊师在医疗健康系统的知识中介和转译实践为切入点进一步拓展了相关讨论" | 方法嵌入问题陈述，不单独成段 |
| "首先，……其次，……最后，……" | "研究发现：……——即便……" | 用"——"和冒号承接，避免断裂式连接 |
| "本研究采用XX理论框架，结合XX方法，运用XX工具，进行XX分析" | "本研究通过一组混合研究设计，从传播研究的两个重点面向——内容与效果层面联合探究了一个问题" | 用"——"破折号展开解释，避免术语堆砌 |

**修复步骤**：
1. 识别方法是否独立成段或机械罗列
2. 提取方法的核心动词（通过、结合、采用、聚焦等）
3. 将方法嵌入问题陈述之后，形成"问题→方法"的自然流动
4. 用"——"破折号展开解释，避免术语堆砌
5. 用"研究发现：""并认为"等承接式表达引出发现，避免断裂式编号

## 人类语言合规基准（★v1.5新增）

> 本章节为v1.5新增的强制合规检查机制，与 `human_language_features.md` 配套使用。
> 本文件（style_standards.md）定义"风格标准"的禁止与引导规则，`human_language_features.md` 定义"人类语言合规基准"的指纹性特征。两者互为补充：本文件管"不能怎么写"，`human_language_features.md` 管"应该怎么写"。

### 与 human_language_features.md 的关系

| 文件 | 定位 | 作用 | 检查方向 |
|------|------|------|---------|
| `style_standards.md`（本文件） | 风格标准 | 禁止违规模式 + 正面引导 | 负向检查（不能怎么写） |
| `human_language_features.md` | 人类语言合规基准 | 人类论文指纹性特征 | 正向检查（应该怎么写） |

**互补关系**：
- 本文件定义的"断裂式表达""机械过渡句""公式化辞藻"等禁止模式，对应 `human_language_features.md` 第四章"AI论文典型问题清单"
- 本文件定义的"好语言5项核心特征"，对应 `human_language_features.md` 第三章"人味特征清单"
- 本文件定义的"语义衔接质量判断标准"，对应 `human_language_features.md` 第五章"话语表述的逻辑特征"

### 强制人类语言合规检查标准（引用 human_language_features.md 第六章）

所有审稿Agent必须参照 `human_language_features.md` 第六章的强制合规检查标准进行人类语言合规检查。检查分为四层：

#### 第一层：微观层面检查（句式/词汇/标点）

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 6.1.1 句长方差 | 全文句长标准差≥10.0 | 按句号分割全文，计算句长标准差 |
| 6.1.2 段落开头多样性 | 段落开头句式类型≥5种 | 统计每段首句的句式类型 |
| 6.1.3 AI高频词检测 | "值得注意的是"≤1次/千字；"综上所述"≤1次/千字；"总而言之"禁止使用；"此外/另外"作为段落开头≤2次/全文；"首先/其次/再次/最后"作为段落开头禁止使用 | 正则匹配+频率统计 |
| 6.1.4 短句收束 | 每段末尾应有短句（≤20字）作判断收束 | 检查每段最后一句的字数和句式 |
| 6.1.5 破折号/引号功能 | 破折号、引号使用符合人类论文的多功能特征 | 检查破折号是否用于解释/转折/强调/列举，引号是否用于概念界定 |

#### 第二层：中观层面检查（章节风格）

| 检查项 | 标准 |
|--------|------|
| 6.2.1 摘要结构 | 摘要符合学科主导结构（传播学五要素/经济学六段式/法学三段式/民族学三重结构/非遗三段式） |
| 6.2.2 引言风格 | 引言以"具体场景"或"理论对话"开篇，而非泛泛而谈 |
| 6.2.3 文献综述对话性 | 文献综述呈现"对话"而非"罗列"，有"缺口识别"和"对话推进" |
| 6.2.4 结论批判性关怀 | 结论部分有"批判性关怀温度"，从学术分析上升到社会关怀 |

#### 第三层：宏观层面检查（论证/过渡/声音）

| 检查项 | 标准 |
|--------|------|
| 6.3.1 论证结构 | 论证结构符合学科主导模式，有让步-转折、递进-收束 |
| 6.3.2 过渡方式 | 过渡以语义衔接为主，连接词为辅（概念锚定/经验切入/理论对话/转折推进/递进深化） |
| 6.3.3 作者声音 | 有明确的作者声音，使用"我们""本文""笔者"作判断主语 |
| 6.3.4 隐喻体系化 | 核心隐喻贯穿全篇，形成"意象网络" |
| 6.3.5 概念命名 | 有概念命名冲动，新概念有理论锚点 |

#### 第四层："人味"特征检查

| 检查项 | 标准 |
|--------|------|
| 6.4.1 "人味"特征数量 | 全文至少体现3项"人味"特征（见human_language_features.md第三章） |
| 6.4.2 学科适配 | "人味"特征与学科适配（传播学/经济学/法学/民族学/非遗各有侧重） |

### 强制要求

> ⚠️ **所有审稿Agent必须参照 `human_language_features.md` 进行人类语言合规检查。**

1. **审稿Agent强制参照**：ExternalReviewer、AdversarialCritic在评审时，必须以 `human_language_features.md` 为人类语言特征的参照标准，将人类语言合规性纳入9维度评分（特别是维度6"文笔与文风"和维度7"逻辑缜密度"）。

2. **修改Agent强制参照**：AbstractReviser、IntroductionReviser、LiteratureReviewReviser、FindingsReviser、FullTextPolisher在修改时，必须参照 `human_language_features.md` 的特征清单和检查标准，确保输出符合人类论文的语言逻辑、习惯、规范。

3. **程序化强制检查**：`pipeline/style_guard.py` 的 `check_human_language_compliance()` 函数实现微观层面的程序化检查（句长方差、段落开头多样性、AI高频词、短句收束），作为人类语言合规的"第一道防线"。

4. **综合合规判定**：参照 `human_language_features.md` 第6.5节"综合合规判定"标准
   - **通过**：所有检查项均通过，或仅有≤2项轻微未通过
   - **有条件通过**：3-5项检查项未通过，但核心检查项（6.1.1、6.1.3、6.2.1、6.3.2）均通过
   - **未通过**：核心检查项未通过，或≥6项检查项未通过——**未通过的论文不得输出**

## 古典汉语词汇研究类型分级使用指南（★v7.4新增：审稿视角）

> 本指南与 gen/kb/human_language_features.md 4.2.1 节完全对齐，但表述视角为"审稿检查"。
> 审稿人在检查论文时，应按本指南逐项核查文言词汇的使用合规性。

### 一、三级词表审稿核查清单

#### 通用级（所有研究类型可用，审稿通过）

| 词汇 | 每千字上限 | 审稿要点 |
|------|----------|---------|
| 亦 | 2 | 检查是否为功能性使用（如"亦构成"），非装饰性堆砌 |
| 或 | 2 | 检查是否表达不确定性，非机械替换"也许" |
| 由此 | 2 | 检查是否承接前文因果，非突兀出现 |
| 然而 | 3 | 检查是否承接前文转折，非段首机械过渡 |
| 因而 | 2 | 检查是否表达因果推断，非与"因此"混用 |
| 综上 | 1 | 检查是否位于章节末尾收束，非段中滥用 |
| 事实上 | 1 | 检查是否引出反常发现，非空泛修饰 |
| 并非 | 2 | 检查是否构成否定判断，非双重否定冗余 |
| 鉴于 | 1 | 检查是否引出因果前置，非"由于"的同义替换 |
| 换言之 | 1 | 检查是否对前文进行转述，非无前文承接 |

#### 学科级（仅 qualitative/interview_report/theoretical 可用，审稿需查研究类型）

| 词汇 | 每千字上限 | 审稿要点 | 禁用研究类型 |
|------|----------|---------|-------------|
| 诸如 | 2 | 检查是否引出举例，非"比如"的同义替换 | quantitative/mixed/computational |
| 譬如 | 1 | 检查是否引出文献对话，非装饰性使用 | quantitative/mixed/computational |
| 抑或 | 1 | 检查是否构成选择判断，非"或者"的同义替换 | quantitative/mixed/computational |
| 诚然 | 1 | 检查是否构成让步转折，非空泛修饰 | quantitative/mixed/computational |
| 故 | 2 | 检查是否表达因果推断，非"所以"的同义替换 | quantitative/mixed/computational |
| 然则 | 1 | 检查是否承接前文转折，非段首机械过渡 | quantitative/mixed/computational |
| 遑论 | 1 | 检查是否表达递进否定，非空泛修饰 | quantitative/mixed/computational |
| 概言之 | 1 | 检查是否位于章节末尾收束，非段中滥用 | quantitative/mixed/computational |

#### 禁用级（全部研究类型禁用，审稿直接判违规）

| 词汇 | 审稿处理 | 替代方案建议 |
|------|---------|------------|
| 凡此种种 | 直接判违规，要求替换 | 综上、综合上述 |
| 盖因 | 直接判违规，要求替换 | 原因在于、由于 |
| 是以 | 直接判违规，要求替换 | 因此、所以 |
| 亦或 | 直接判违规，要求替换 | 或者、抑或（仅学科级可用） |
| 诚如 | 直接判违规，要求替换 | 正如、如前所述 |

### 二、审稿判定流程

1. **第一步：研究类型识别**——从论文元数据或内容判断 research_type
2. **第二步：禁用级扫描**——出现任一禁用级词汇，直接判违规
3. **第三步：学科级守卫**——若 research_type ∈ {quantitative, mixed, computational}，出现任一学科级词汇，判违规
4. **第四步：总量核查**——通用级+学科级词汇总数 ≤3 次/千字，单一词汇 ≤1 次/千字
5. **第五步：段落限制**——同一段落不超过 2 种文言词汇

### 三、审稿视角的典型问题示例

**问题 1：研究类型守卫违规**
- 论文 research_type = quantitative
- 出现"抑或"→ 直接判违规（quantitative 禁用学科级）

**问题 2：禁用级词汇**
- 出现"凡此种种"→ 直接判违规（全禁）

**问题 3：总量超限**
- 千字内出现"亦""或""由此""然而""因而"5 个通用级词汇 → 总量 5 > 3，判违规

**问题 4：段落堆砌**
- 同一段落出现"亦""或""由此""然而"4 种文言词汇 → 超过 2 种，判违规
