CNKI Auto-Download Setup

This will enable FULLY AUTOMATIC PDF downloads from CNKI paper pages.

Step 1: Install Tampermonkey

Tampermonkey is a browser extension that runs custom scripts on websites.

Install for Chrome Install for Edge

If the links don't work, search "Tampermonkey" in your browser's extension store.

Step 2: Add the CNKI Auto-Download Script

Click the Tampermonkey icon → "Create a new script..." → Replace all content with the code below → Save (Ctrl+S)

Step 3: Open the Download Page

Once Tampermonkey is set up, open the download page:

Open V2 Download Page (400 Papers)

Press S on the download page to start auto-opening papers.

Each paper detail page will auto-download PDF thanks to Tampermonkey!

How it works: Tampermonkey runs the script on every CNKI paper detail page. The script automatically finds the "PDF下载" button and clicks it, triggering the download. Your browser's CNKI cookies handle the authentication chain automatically.

Troubleshooting: If PDFs aren't downloading:
1. Make sure Tampermonkey is enabled (icon should be colored, not gray)
2. Check that your browser has CNKI login cookies (visit www.cnki.net to verify)
3. Open a paper page manually and check if the script runs (you'll see a blue bar at the top)
