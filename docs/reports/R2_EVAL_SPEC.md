# R2 人工质量评估规范（T21 / AT-050）

> 编制：2026-11-20 · Lead。依据：PRD v1.0 FR-07/FR-15/FR-16、Playbook T21、
> 验收矩阵 AT-050。**本文是评估方法说明，不是评估结果**；结果见 `R2_EVAL_STATUS.md`。

## 1. 为什么必须真人盲评

PRD 明确禁止"模型评分冒充真人意见"（AT-050）。研究质量涉及问题识别是否准确、
证据是否支撑结论、修改是否保住作者原意、审阅效率是否真的提升——这些只有领域读者能判断。
所以 R2 的质量结论只能来自两位真人对授权论文的独立评分，工具只负责汇总。

## 2. 样本要求

| 项 | 要求 |
| --- | --- |
| 数量 | ≥ 10 份（AT-050 下限），建议 12–20 份以便分层 |
| 授权 | 每份都有书面授权或明确开放授权，记录在 `license` 与 `source` 字段 |
| 正文 | **不进入仓库**；仓库只保存清单（标题/授权/来源/长度/方法/参照缺陷） |
| 分层 | 覆盖不同篇幅（8k–25k 字）、不同方法（量化/质性/混合/计算传播/理论）、不同成熟度 |
| 参照缺陷 | 每份由未参与评分流程的第三人预先标注真实缺陷，作为召回率分母 |

## 3. 评分维度

| 维度 | 定义 | 取值 |
| --- | --- | --- |
| `defect_recall` | 报告是否找出该文真实存在的问题（对照参照缺陷） | pass / partial / fail |
| `false_positive` | 报告是否提出不存在或不重要的问题 | pass（几乎无误报）/ partial / fail |
| `evidence_support` | 结论是否有位置与依据支撑，而非泛泛而谈 | pass / partial / fail |
| `revision_conservation` | 修改建议是否保住原意、数据、引文与作者语气 | pass / partial / fail |
| `time_minutes` | 评审完成该文诊断+审阅所花的分钟数 | 数值（分钟） |

`pass=1 / partial=0.5 / fail=0` 只用于汇总展示，不改变"这是人工判断"的事实；
数值缺失就是缺失，汇总里输出 `null`，**不补 0**。

## 4. 盲评流程

1. 样本编号后交给两位评审，**双方互不知道对方身份与结果**，评审也**不看**模型输出以外的团队结论。
2. 两位评审都独立完成同一批样本的 5 个维度评分，写入各自的 CSV。
3. 汇总前先做输入校验：样本数、评审人数、评审人 id 不得像模型、授权字段齐全。
4. 汇总后先看一致率与 Cohen's κ，再看召回/误报/时间；κ 低于 0.4 的分歧必须回到原文复核。
5. 分歧清单作为"标准不清晰"的信号，不允许取平均糊过去。

## 5. 工具与命令

```bash
python tools/research_quality_eval.py \
    --manifest samples.json \
    --rater-a rater_a.csv --rater-a-id rater_zhang \
    --rater-b rater_b.csv --rater-b-id rater_li \
    --out out/r2_eval_report.json
```

评分 CSV 格式：

```csv
sample_id,dimension,verdict,notes
paper-001,defect_recall,pass,找出方法与样本不匹配问题
paper-001,time_minutes,42,
```

退出码：`0` 汇总完成；`2` 输入不合法；`3` 数据不完整（列出 missing 清单，不生成报告）。
工具**不会**生成任何评分，输出 `source` 固定为 `human_raters`。

## 6. AT-050 映射

| AT-050 要求 | 本规范的落点 |
| --- | --- |
| R2 至少 10 份真实授权论文 | 第 2 节样本要求（工具强制 ≥10） |
| 两位领域评审独立评价 | 第 4 节盲评流程 + 工具强制两位不同真人 |
| 模型评分不能冒充真人意见 | 工具拒绝 model/ai/self 评审人，输出带免责声明 |
| 报告样本量、覆盖、缺陷识别/误报/采纳/时间 | 汇总报告含 sample_count / 维度一致率 / 召回 / 误报 / 时间 |
