# 任度 AI 招聘中枢 UI/UX 原型

一个无构建依赖的多页面高保真前端原型，覆盖：

- 公开品牌首页
- 闪电筛产品页
- 急速面产品页
- 完整招聘工作流
- 产品演示中心
- 首次使用教程
- 登录/注册交互
- 登录后招聘工作台
- 智能筛选工作台
- AI 面试报告

## 本地预览

在本目录运行任意静态文件服务，例如：

```powershell
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 原型说明

- 所有数据均为演示数据。
- 登录仅模拟交互，不提交真实账号。
- 首次点击“开始体验”会进入 5 步教程，之后进入登录窗口。
- 可在页脚或工作台帮助入口重新播放教程。
