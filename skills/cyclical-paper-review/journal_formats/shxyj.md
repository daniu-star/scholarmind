# 《社会学研究》格式规范 v1.1

> **cyclical-paper-review pipeline 适配版**：本规范用于审稿优化流程，
> 配合 9 维度评分体系（选题与问题意识、理论框架与文献、研究设计与方法、
> 研究发现与结果、讨论与理论对话、文笔与文风、逻辑缜密度、严谨性与规范性、
> 创新性与启发价值）对论文进行格式合规性审查与修订。

## 一、期刊基本信息

- 期刊名称：《社会学研究》（Sociological Studies）
- 主办单位：中国社会科学院社会学研究所
- 刊期：双月刊
- 级别：CSSCI来源期刊、北大核心期刊
- 学科领域：社会学、社会工作、人口学、人类学
- 期刊标识符（config.py）：`shxyj`

---

## 二、页面排版

### 2.1 基本设置
- 纸张大小：A4（210mm × 297mm）
- 页边距：上2.54cm、下2.54cm、左3.17cm、右3.17cm
- 排版密度：每页34行，每行36字
- 文件格式：Word

> **config.py 对应**：`page_layout: {"lines_per_page": 34, "chars_per_line": 36}`

### 2.2 字体规范
- 正文：宋体，五号（10.5pt），1.5倍行距
- 一级标题：黑体，三号（16pt），居中
- 二级标题：黑体，四号（14pt），左对齐
- 三级标题：楷体，小四号（12pt），左对齐
- 四级标题：宋体，五号（10.5pt），左对齐
- 脚注：宋体，小五号（9pt），单倍行距

> **config.py 对应**：`font_title_3: "楷体"`、`size_title_3: 12`、`line_spacing: 1.5`

---

## 三、标题层级

```
一级标题：一、二、三、……
二级标题：（一）（二）（三）……
三级标题：1. 2. 3. ……（半角句点+空格）
四级标题：（1）（2）（3）……
```

> **config.py 对应**：`title_hierarchy: ["一、", "（一）", "1.", "（1）"]`

---

## 四、注释体例

### 4.1 基本规则
- 注释采用**页下脚注**形式
- 注释序号用 ①②③…… 标识
- **每页独立排序**
- 正文中注释序号置于标点符号之后的右上角

> **config.py 对应**：
> - `citation_style: "footnote"`
> - `footnote_format: "per_page"`
> - `footnote_marker: "[1][2][3]"`

### 4.2 注释内容
- 说明性注释：对正文中某处内容的补充说明
- 引用性注释：标明引文出处

### 4.3 中文文献注释格式

#### 著作
> 作者：《书名》，出版地：出版社，出版年，第X页。

#### 期刊论文
> 作者：《论文题名》，《期刊名》出版年份第X期，第X-X页。

#### 学位论文
> 作者：《论文题名》，博士学位论文，学校名称，年份。

#### 报纸文章
> 作者：《文章题名》，《报纸名称》年月日，第X版。

---

## 五、参考文献格式

### 5.1 基本要求
- 参考文献置于**文末**，另起一页
- 标题为"参考文献"（不编号）
- 中英文文献分开排列：先中文，后英文
- 中文文献按作者姓氏拼音排序
- 英文文献按作者姓氏字母排序

### 5.2 中文文献格式（GB/T 7714-2015）

#### 期刊论文
```
[1] 作者. 题名[J]. 刊名, 出版年份, 卷号(期号): 起止页码.
```

#### 专著
```
[2] 作者. 书名[M]. 出版地: 出版社, 出版年份.
```

#### 学位论文
```
[3] 作者. 题名[D]. 保存地点: 保存单位, 年份.
```

#### 析出文献
```
[4] 作者. 析出文献题名[M]//文集编者. 文集题名. 出版地: 出版社, 出版年份: 起止页码.
```

### 5.3 英文文献格式（APA 7th）
```
Author, A. A. (Year). Title of article. Title of Periodical, Volume(Issue), pages. https://doi.org/xxxxx

Author, A. A. (Year). Title of book. Publisher.

Author, A. A. (Year). Title of chapter. In E. E. Editor (Ed.), Title of book (pp. xx-xx). Publisher.
```

## 六、摘要与关键词

### 6.1 中文摘要
- 字数：**300-500字**
- 内容要素：
  1. 研究问题与背景
  2. 研究方法与数据来源
  3. 主要研究发现
  4. 理论意义与结论
- 格式："摘要："加粗，冒号后直接开始正文

### 6.2 英文摘要（Abstract）
- 内容与中文摘要对应
- 字数：200-300 words
- 格式："Abstract:" 加粗，冒号后直接开始正文

### 6.3 关键词
- 数量：**3-5个**
- 中英文关键词一一对应
- 关键词之间用分号（；）分隔
- 格式：
  > 关键词：关键词1；关键词2；关键词3
  > Keywords: keyword1; keyword2; keyword3

---

## 七、图表规范

### 7.1 表格规范
- 采用**三线表**格式
- 顶线（反线/粗线）、栏目线（正线/细线）、底线（反线/粗线）
- 无竖线、无多余横线
- 表题置于表格**上方**，格式为 "表1　表题内容"
- 表头加粗，数据居中或左对齐
- 表注置于表格下方，用小号字体，以"注："开头
- 表格宽度不超过版心宽度
- 图表原则上不跨页

> **config.py 对应**：`table_style: "three_line"`

### 7.2 图片规范
- 图题置于图**下方**，格式为 "图1　图题内容"
- 分辨率 ≥ 300dpi
- 格式优先SVG/PDF矢量格式，其次PNG/TIFF
- 所有图表需有**自明性**（脱离正文也能独立理解）

### 7.3 图表编号
- 全篇连续独立编号（表1-表N，图1-图N）
- 不在图表编号前加章节号

## 八、研究伦理声明

### 8.1 基本要求
《社会学研究》要求所有涉及人类受试者的研究，在论文中声明研究伦理合规性。

### 8.2 声明内容
在"研究方法"部分包含以下内容：

1. **伦理审查**：说明研究是否经过机构伦理审查委员会（IRB）审批，提供审批编号
2. **知情同意**：说明是否获得受访者的知情同意，同意形式（书面/口头）
3. **匿名化处理**：说明对受访者信息的匿名化处理方式
4. **数据安全**：说明数据的存储和保护措施
5. **利益冲突**：如存在利益冲突，需声明

### 8.3 声明模板
> 本研究已通过XX大学伦理审查委员会审批（审批编号：XXX）。所有受访者均已签署知情同意书。文中所有人名、地名均已做匿名化处理。研究数据已脱敏并安全存储于加密设备中。作者声明无利益冲突。

### 8.4 特殊人群研究附加要求
如果研究对象为**弱势群体**（如老年人、未成年人、残障人士等），需：
- 说明采取的特殊保护措施
- 说明是否获得监护人/法定代理人的同意
- 说明研究对受访者的潜在风险及风险最小化措施

## 九、其他规范

### 9.1 外国人名
- 第一次出现时翻译为中文，括号标注外文原名
- 后续出现直接使用中文译名

### 9.2 数字用法
- 遵照国家标准《出版物上数字用法》（GB/T 15835-2011）

### 9.3 项目资助
- 在首页脚注中标明：
  > *本文系国家社会科学基金项目"XXX"（编号：XXX）的阶段性成果。

### 9.4 匿名评审
- 正文中不得出现作者姓名、单位等信息
- 致谢部分暂不放入投稿版本

## 十一、与 cyclical-paper-review 的配合使用说明

### 11.1 概述

本格式规范在 cyclical-paper-review pipeline 中作为**期刊格式约束**注入审稿优化流程，
由 `constraint_injector.py` 在每轮循环开始时注入到各 Agent 的指令中，
由 `style_guard.py` 进行程序化格式合规性检测。本规范与 `config.py` 中的
`JOURNAL_CONFIGS["shxyj"]` 保持一致，确保审稿优化后的论文符合《社会学研究》
的投稿格式要求。

### 11.2 与 9 维度评分体系的对应关系

本格式规范主要影响以下评分维度：

| 评分维度 | 分值 | 格式规范的关联点 |
|---------|------|----------------|
| **文笔与文风**（writing_style） | 12分 | 标点符号规范（破折号/冒号/引号）、语言自然度、行文呼吸感 |
| **严谨性与规范性**（rigor_norm） | 7分 | 文献引用格式真实准确、脚注体例正确、研究伦理声明完整、格式标准统一 |
| **逻辑缜密度**（logic_rigor） | 10分 | 标题层级递进、段落逻辑过渡（间接关联） |
| **研究设计与方法**（research_design） | 15分 | 研究伦理声明合规性（IRB审批、知情同意、匿名化处理） |
| **研究发现与结果**（findings） | 12分 | 图表三线表规范呈现、自明性（间接关联） |

### 11.3 关键格式合规检测点

在 cyclical-paper-review pipeline 中，`style_guard.py` 会对以下格式要素进行
程序化检测，违反将触发修订循环：

1. **标题层级**：必须使用 `["一、", "（一）", "1.", "（1）"]` 四级体系，
   三级标题使用半角句点+空格
2. **三级标题字体**：使用楷体小四号（与 config.py 一致）
3. **脚注体例**：采用页下脚注，每页独立排序，序号格式为 `[1][2][3]`
4. **排版密度**：每页34行×36字
5. **参考文献**：文末列表，中英文分开，中文用 GB/T 7714-2015，英文用 APA 7th
6. **摘要规范**：中文300-500字，英文200-300 words，关键词3-5个
7. **图表规范**：三线表格式，表题在上、图题在下，全篇连续独立编号
8. **研究伦理声明**：涉及人类受试者的研究须声明 IRB 审批、知情同意、匿名化处理
9. **匿名评审**：正文不得出现作者信息，致谢部分暂不放入

### 11.4 在 pipeline 各阶段的运用

| Pipeline 阶段 | 格式规范的运用方式 |
|--------------|------------------|
| **constraint_injector**（约束注入） | 将本规范的关键格式要求（含研究伦理声明）注入到各 Agent 指令中 |
| **external_reviewer**（外审专家） | 按 9 维度评分时，rigor_norm 与 research_design 维度依据本规范检查格式与伦理合规性 |
| **abstract_reviser**（摘要修改者） | 依据本规范检查摘要字数（300-500字）与关键词数量（3-5个） |
| **findings_reviser**（研究发现修改者） | 依据本规范检查图表三线表格式与自明性 |
| **full_text_polisher**（全文润色者） | 依据本规范进行最终格式统一、参考文献体例校对、研究伦理声明核查 |
| **style_guard**（风格守卫） | 程序化检测标题层级、脚注格式、字体规范等是否合规 |
| **format_output**（格式输出） | 输出 Word 文档时按本规范应用字体、字号、页边距等设置 |

### 11.5 通过阈值与格式合规

cyclical-paper-review pipeline 的通过阈值为 **95 分**（满分 100 分）。
其中 `rigor_norm`（严谨性与规范性，7分）维度直接关联格式合规性与研究伦理声明，
`research_design`（研究设计与方法，15分）维度关联研究伦理合规性。
若格式不规范或伦理声明缺失将导致相关维度失分，可能影响整体评分达到通过阈值。
因此，本格式规范（含研究伦理声明要求）的严格执行是论文通过审稿优化流程的必要条件之一。

### 11.6 配置引用

在 `config.py` 中通过以下方式引用本规范：

```python
JOURNAL_CONFIGS["shxyj"] = {
    "name": "社会学研究",
    "page_layout": {"lines_per_page": 34, "chars_per_line": 36},
    "title_hierarchy": ["一、", "（一）", "1.", "（1）"],
    "citation_style": "footnote",
    "footnote_format": "per_page",
    "footnote_marker": "[1][2][3]",
    "table_style": "three_line",
    "word_template": {"font_title_3": "楷体", "size_title_3": 12, "line_spacing": 1.5, ...},
    # ... 完整配置详见 config.py
}
```

使用时通过 `PipelineConfig(journal_style="shxyj")` 指定目标期刊为本规范。
